# TruthRaw current claim map — 2026-09-11

This file states what each major claim is allowed to mean. It is intentionally stricter than a feature list.

| Claim | Allowed current statement | Forbidden overclaim |
|---|---|---|
| Original RAW evidence | Exact sealed source bytes/Direct-CFA samples are evidence where admitted. | A decoded/rendered/exported image is not a second independent measurement. |
| Single-frame evidence count | Ordinary lineage is 1 physical frame / 1 independent evidence source. | Virtual views, duplicate URIs, decoded buffers or previews do not increment evidence. |
| v4.7i reconstruction | Measured-preserving single-frame reconstruction baseline. | No claim of semantic/generative recovery of unknowable detail. |
| Zero-line | `T=log2(L/L0)` shared reference gauge. | Not BlackLevel, zero photons, clipping or display black. |
| TruthRange | Representation can span more numeric range than source/export while support/uncertainty stay explicit. | Unbounded numeric address space is not unbounded knowledge. |
| Resource adaptation | Different devices may use different tiles/workers/cache/scheduling. | More RAM/CPU/GPU cannot grant stronger truth. |
| Native DNG | Strict certified TileNative subset can bypass Gatehouse. | `.dng` extension alone does not imply native admission. |
| Professional RAW ingress | Container/topology/compression/certification can be classified. | Classification is not successful pixel decode. |
| LibRaw probe | Metadata/topology compatibility probe is validated with LibRaw 0.21.2. | Probe camera count or `open_file` success is not scientific format certification. |
| External decoder | A future named codec path may become `LosslessDecodedCertified` after sample-equivalence proof. | Decoder output is not automatically DirectNativeCertified. |
| Gatehouse | Decoder state/resources can be isolated, audited and detached before Main House. | Gatehouse is not a second Scientific Master/zero-line/evidence pipeline. |
| Decoded handoff | Integrity-verified decoded Bayer representation can be persisted/read boundedly on validated branch. | Transport CRC is not source evidence identity and handoff is not new evidence. |
| Android color preview | Current build path produces a source-bound appearance role with DNG metadata color authority. | It is not yet a finalized Scientific Preview, Scientific Master or FULL_PHYSICAL color result. |
| DNG color metadata | `SOURCE_METADATA_BOUND` can faithfully bind rendering metadata to exact source bytes. | It is not independent camera/lens spectral calibration. |
| Preview JPEG | Portable 8-bit sRGB appearance/compatibility artifact. | JPEG may never become evidence, calibration or numeric master validation. |
| Counterfactual illumination | May describe a separately labeled hypothetical world. | It may not rewrite the evidence for the original world. |
| Multi-capture/HDR | Only explicit future governed real captures may increase measurement count after alignment/timing/motion/occlusion/independence contracts. | Batch selection, VOM or one computational RAW must not be silently called independent multi-frame evidence. |

## Current claim ceiling

The strongest current Android visible claim is **source-bound appearance from admitted source metadata**, not final physical color truth. Final Scientific Preview authority requires a deterministic Scientific Master identity and phase-2 Backplane finalization. Physical camera/lens truth requires additional independent calibration/evidence beyond source rendering metadata.

## No blanket RAW claim

TruthRaw must never advertise “all RAW files supported” based on extension lists. Maintain a named certification matrix by camera/codec/compression/topology/decoder version/build/sample-equivalence result. Unsupported or unverified combinations remain ResearchOnly/Derived/Blocked according to ingress rules.
