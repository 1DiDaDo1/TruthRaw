## Continuation protocol

A future short continuation command such as `Begin`, `Ga verder`, or `Ga door` means: re-fetch the live project/PR state, recover the relevant knowledge pack, then continue autonomously with the next scientifically justified step. Do not ask the user to restate already documented project history.

## Authority rule

Knowledge preservation is not canon promotion. Use this order when resolving conflicts:

`live repository -> explicit current-state/status docs -> canonical docs -> validated research -> handoffs -> historical transcript`

Never delete a failed/rejected historical path merely because it is no longer current. Preserve it as provenance so the project does not repeat the same mistake.

## Non-negotiable laws

**Measured where measured. Reconstructed where necessary. Never invented.**

**Representation can exceed the source. Knowledge claims cannot exceed the evidence.**

Normal scene evidence remains one physical frame and one independent evidence root. Multi-frame calibration datasets estimate a camera/system model but do not become extra evidence for a later single scene.
