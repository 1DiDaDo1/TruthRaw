<summary><strong>4. Scientific foundation — grouped by discipline</strong></summary>

External knowledge improves contracts, models and tests. It never becomes source-specific evidence merely because it is true in general.

## Photography / RAW / CFA / sensor metrology

- Sensel values are measurements influenced by photon statistics, read/electronic noise, dark/fixed-pattern behavior, quantization, black reference, gain chain and saturation/censoring.
- Scientific denoise/reconstruction belongs in evidence-weighted estimation with explicit uncertainty, not generic RGB smoothing.
- CFA phase, sampling geometry and measured-channel identity matter.
- BlackLevel, effective black, WhiteLevel, physical clipping/censoring and display black/white are different concepts.
- Source-contained calibration can be used only within validated semantics/domain.

Primary metrology anchor: **EMVA 1288 Release 4.0**.

## DNG / raw-to-linear semantics

Normative DNG anchor: **Adobe DNG Specification 1.7.1.0**.

Normative order relevant here:

`Linearization -> Black Subtraction -> Rescaling / Normalization -> Clipping`

Specification knowledge does not create observation-specific admission/use.

## Optics / lens / PSF / OTF / MTF / sampling

- Pixel dimensions are not independently resolved scene detail.
- Real resolution depends on lens, diffraction/aberrations, PSF/OTF/MTF, sensor aperture, sampling lattice, CFA and processing.
- Denser resampling does not create measured spatial bandwidth.
- Sharpening should follow demonstrated optical/support structure.

Current standard anchor: **ISO 12233:2024**.

## Radiometry / photometry / physically based rendering / artificial light

- Emission and reflection/transmission are physically distinct.
- Light transport must keep emitted radiance separate from reflected/scattered incident radiance.
- Radiometric scene formation remains separate from display Appearance.
- Narrowband/LED/OLED spectra can create camera-vs-human observer mismatch.
- RGB is not a unique spectrum.
- Small emissive glyphs can interact with optical PSF, display subpixel geometry, sensor aperture and CFA differently from large uniform fields.

Useful physical anchor: PBRT 4th edition and university radiometry/rendering material.

## Human vision / colour appearance / depth perception

- Human appearance depends on adaptation, luminance, surround, local contrast, colour relations and viewing conditions.
- Scene-referred scientific colour formation and display-referred Appearance remain separate.
- Single-view depth has fundamental ambiguities.

Current appearance anchor: **CIE 248:2022 — CIECAM16**.

## 3D / projective geometry / architecture

- Lines, planes, vanishing points, homographies and multi-view constraints can provide strong geometric evidence.
- A single view normally does not determine unique metric depth, material, scale and illumination.
- Multi-observation enrichment requires separately sealed observations and a proven relation with uncertainty/authority.

## Stop-motion / exposure integration / temporal aliasing / rolling shutter

- A geometrically static scene need not have time-constant radiance.
- Camera exposure integrates over time.
- PWM, LED drivers, display refresh/scanout and rolling shutter can alter measured colour/luminance with exposure duration/phase and row timing.
- Do not solve temporal/spectral phenomena with a semantic screen recolour detector.

Current temporal-light anchor: **CIE 249:2022-Cor1**.

## Restoration / conservation analogy

Treat sealed observation evidence like an original conservation object:

- preserve the original;
- document intervention;
- minimize destructive intervention;
- keep provenance explicit;
- distinguish reconstruction from original evidence;
- prefer reversible/retreatable downstream work where practical.

This is governance inspiration, not imaging authority.
