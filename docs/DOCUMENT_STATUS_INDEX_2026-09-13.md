## Conflict resolution rule

If two documents disagree:

1. source evidence/manifests/tests control claims about their own recorded experiment;
2. module-local canonical documentation controls the exact module/version;
3. the newest current global state/index controls which project-level entrypoints are current;
4. the 2026-09-14 zero-line empirical overlay controls the newest source-bound Honor ISO/response/dark findings without silently upgrading them to independent physical calibration;
5. a newer project map does **not** turn an old failed experiment into a pass;
6. recovered chat/design history explains rationale but does not override exact module evidence;
7. a branch name, chat summary, screenshot, or README title alone is never sufficient to promote scientific authority.
