## Important scientific limit

Candidate 1 is **not** declared safe for correction.

Reasons:

- r=16 already contains 7 structure-protected samples;
- r=32 contains 25;
- r=64 contains 159;
- the candidate rectangle itself contains 327 structure samples;
- current N2 sample grid is sparse (period 8), so absence of a sampled protected point inside r=8 is not proof that continuous scene structure is absent;
- no local reconstruction validity test has yet been run in the lattice;
- no uncertainty field has yet been assigned to unanchored lattice positions.

Therefore:

- `chroma_correction_supported=false`;
- `private_ab_delta_allowed=false`;
- `scientific_writeback_allowed=false`.
