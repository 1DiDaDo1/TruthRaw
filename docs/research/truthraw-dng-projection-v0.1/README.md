# TruthRaw DNG Projection v0.1

Status: **RESEARCH IMPLEMENTATION — VALIDATION PENDING**

## Purpose

Provide standards-oriented DNG compatibility projections downstream of an already finalized TruthRaw Scientific Preview lineage without changing the sealed source, Scientific Master, TruthRange gauge, Technical Backplane, color authority, evidence count, or appearance pipeline.

This module is intentionally an **Exporter / Projection** layer. It is not a decoder, not a new evidence source, and not a replacement for the Scientific Master.

## Projection roles

### `TRUTHRAW_STAGE2_CFA_PROJECTION`

- DNG raw IFD with `PhotometricInterpretation = CFA (32803)`;
- one IEEE-754 binary32 sample per physical CFA site;
- pixels are the existing Stage-2 values after the validated black/white normalization, residual-black correction when available, and GainMap application when present;
- no missing color channel is invented at a sensor site;
- output role is **DERIVED_MEASUREMENT / compatibility projection**;
- output is **not** immutable Direct-CFA evidence and does not create a second evidence root.

This is the closest v0.1 DNG equivalent to a TruthRaw “rawsensor” output while retaining explicit scientific provenance.

### `TRUTHRAW_LINEAR_RAW_PROJECTION`

- DNG raw IFD with `PhotometricInterpretation = LinearRaw (34892)`;
- three IEEE-754 binary32 camera-native RGB samples per pixel;
- pixels are generated by the exact reconstruction backend used for the Scientific Master, before `camera_to_xyz()`, appearance, tone mapping, gamut mapping, or display conversion;
- output role is **RECONSTRUCTED_COMPATIBILITY_PROJECTION**;
- output is not sensor evidence.

This avoids a scientifically unnecessary reconstructed-RGB → Bayer remosaic → external demosaic round trip.

## Scientific binding

Export is permitted only after a finalized release object exists. During export the module:

1. re-verifies the exact sealed source SHA-256;
2. verifies the prepared source/color identity and 1-frame / 1-evidence-root contract;
3. verifies the Technical Backplane source/master identity;
4. reconstructs the camera-native Scientific Master on the canonical 64×64 grid while streaming the selected projection;
5. recomputes the Scientific Master digest from those exact camera-native RGB tiles;
6. re-verifies the sealed source after the export pass;
7. requires the recomputed master digest to be exactly equal to the finalized release digest.

A digest mismatch is fail-closed. Because a sequential sink cannot retract bytes already written, callers must discard/truncate the destination whenever the returned status is not `OK`.

## Bounded memory

The writer never materializes the full source RAW or full reconstructed RGB frame. It keeps one 64-row output strip, one canonical reconstruction workspace, one row-serialization buffer, the bounded digest state, and the small TIFF/DNG header metadata.

For a 4080-pixel-wide frame this is roughly:

- Stage-2 CFA strip: `4080 × 64 × 1 × 4 ≈ 1.0 MiB`;
- LinearRaw RGB strip: `4080 × 64 × 3 × 4 ≈ 3.0 MiB`;

plus bounded reconstruction/digest/header state.

## DNG container v0.1

The research writer currently emits:

- classic TIFF, little-endian;
- uncompressed strips;
- `RowsPerStrip = 64`;
- `SampleFormat = 3` (IEEE floating point);
- `BitsPerSample = 32`;
- `DNGVersion = 1.4.0.0`;
- `DNGBackwardVersion = 1.4.0.0`;
- explicit `Orientation`;
- synthetic `UniqueCameraModel` identifying the TruthRaw projection role;
- explicit `ImageDescription` containing projection role, exact source evidence ID, and Scientific Master SHA-256.

The source-bound DNG color profile payload is copied from the sealed source IFD0 without upgrading authority: ColorMatrix, CameraCalibration, AnalogBalance, AsShotNeutral/AsShotWhiteXY, CalibrationIlluminant, calibration signatures, and ForwardMatrix tags are preserved when present. `ColorMatrix1` is required for this non-monochrome v0.1 writer.

The v0.1 metadata-copy subset deliberately supports little-endian classic-TIFF source metadata only. BigTIFF and big-endian source metadata fail closed. Output larger than the classic-TIFF 32-bit offset range also fails closed rather than silently switching container semantics.

## Float range

The DNG projection preserves IEEE float32 values as bytes. Stage-2 and camera-native reconstructed values are not forcibly clamped to `[0,1]` by this writer. A downstream DNG reader may apply its own rendering/clipping behavior, which is why the DNG remains a compatibility projection rather than the Scientific Master.

## Authority boundary

The following must remain true for every successful export:

- `createsEvidence = false`;
- `physicalFrameCount = 1`;
- `independentEvidenceCount = 1`;
- `fullFrameMaterialized = false`;
- source metadata color remains source-bound unless a separately validated independent calibration already existed upstream;
- export cannot upgrade `scientificClaimAllowed`;
- representation bytes do not modify the Scientific Master or Backplane.

Canonical rule:

**Measured where measured. Reconstructed where necessary. Never invented.**

## DNG specification / license notice

The implementation targets the floating-point DNG / LinearRaw / CFA semantics defined by the Adobe Digital Negative (DNG) Specification. The code is independently implemented; Adobe SDK source is not copied into this module.
