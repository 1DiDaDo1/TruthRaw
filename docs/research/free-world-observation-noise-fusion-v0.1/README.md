# D.RAW Free-World Observation / Noise Fusion v0.1

Status: EXECUTABLE RESEARCH PRIMITIVE — NOT PRODUCTION-PROMOTED.

This module joins the temporal/multi-view/stop-motion and noise-authority recommendations without changing Direct CFA, Scientific Master or the current single-frame TruthNegative contract.

It provides:
- shot/read variance evaluation for an explicitly calibrated noise model;
- separately sealed observation identity;
- registration and visibility confidence gates;
- inverse-variance fusion only for consistent, non-CENSORED/non-UNKNOWN observations;
- contributor counts and SHA-256 ancestry;
- createsNewEvidence=false and scientificWritebackAllowed=false for the fused estimator.

CENSORED values are deliberately excluded rather than treated as Gaussian samples. A future censored-likelihood fusion must preserve lower bounds.

This primitive does not claim that multiple frames exist. It only becomes multi-frame when separately sealed observations are actually supplied. The existing Camera-5 one-frame Scientific Master remains 1 physical frame / 1 independent evidence item.
