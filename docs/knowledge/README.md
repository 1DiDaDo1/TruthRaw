# TruthRaw knowledge preservation index

Date: 2026-09-14
Status: ACTIVE KNOWLEDGE PRESERVATION OVERLAY

This directory exists so project knowledge recovered or established in long-running design, audit, calibration, reconstruction, product, and validation conversations is not lost when a chat/session ends.

It does not silently replace canonical science. Authority remains:

`live repository -> explicit current-state/status docs -> canonical docs -> validated research -> handoffs -> historical transcript`

The files in this directory are cross-session synthesis and decision-preservation documents. When a statement conflicts with a newer verified live implementation or an explicit canonical document, the newer higher-authority source wins. Historical sections remain provenance and must not be deleted merely because a later design supersedes them.

## Non-negotiable preservation laws

- **Measured where measured. Reconstructed where necessary. Never invented.**
- **Representation can exceed the source. Knowledge claims cannot exceed the evidence.**
- Original source RAW/CFA evidence is immutable/sealed.
- Scientific Master, appearance, counterfactual state, and output projections remain separate.
- Normal photographic evidence remains single-frame: `physicalFrameCount=1`, `independentEvidenceCount=1`.
- Calibration datasets may use many captures, but those calibration frames do not become extra scene evidence for a later photograph.
- APK/GCam/computational-RAW content may not determine TruthRaw evidence, calibration, topology, color, noise, or scientific authority.
- Rejected and failed experiments are preserved as provenance.

## Continuation behavior

When a future project session receives a short continuation command such as `Begin`, `Ga verder`, or `Ga door`, it should first recover the current live branch/PR state and then continue with the next scientifically justified step. It must not reconstruct project history from memory alone when these repository documents are available.
