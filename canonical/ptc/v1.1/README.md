# TruthRaw Pure Truth Certificate — implemented reference v1.1

This package turns the Pure Truth Certificate from a policy into executable gates.

- Python certifier/verifier
- JPEG payload hashing and in-file XMP/copyright embedding
- fail-closed FULL_PHYSICAL readiness gate
- optional Ed25519 signing
- native C++ gate evaluator for mobile/backend integration
- explicit DNG SDK exporter contract
- regression/self-tests

Canonical principle: **Measured where measured. Reconstructed where necessary. Never invented.**
